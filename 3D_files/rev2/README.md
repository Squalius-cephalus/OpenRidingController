
# 3D Printed Parts

It is recommended that the printed part be made from **PETG filament** rather than PLA filament. PLA is too brittle for frame parts.

## Parts for the module

**BOM**

 - 12x 	M3 Bolt 16mm
 - 4x   M3 Bolt 10mm
 - 12x  M3 Heatset insert OD 5mm
 - 2x 608zz Bearing
 
 **Printed parts**

- 1x	Case part 1 - `case_bottom.step`
- 1x	Case part 2 - `case_top.step` 
- 2x Reins case(Mirror the second one) - `reins_case.step`
- 2x Reins flap - `reins_flap.step`
- 2x Bearing collar - `reins_bearing_collar.step`
