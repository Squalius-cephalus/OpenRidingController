
# 3D Printed Parts

The controller consists of FDM-printed parts, metal tubes, and M3 screws. It is recommended that the printed part be made from **PETG filament** rather than PLA filament. PLA is too brittle for frame parts.

## Parts for the frame

**BOM**

  - 3x	16mm stainless steel pipe 700mm
 - 32x 	M3 nut
 - 32x 	M3 Washer 7mm
 - 12x 	M3 Bolt 10mm
 - 24x 	M3 Bolt 16mm
 
 **Printed parts**

- 3x	Frame holder - `frame_main.step`
- 2x	Frame Connector - `frame_connector.step` 
- 4x Accessory Holder - `frame_accessory_holder.step`
- 2x Strap holder *optional* - `strap_holder.step`

## Rein Sensor
You need to make two of these, only sunshade needs to be mirrored in the slicer software. The left and right parts are identical.

**BOM**
 - 2x 	M3 Washer 7mm
 - 7x 	M3 Bolt 10mm
 - 5x M3 Heatset insert OD 5mm
 - 1x 608zz Bearing
 - 2.5mm Elastic cord
 - Paracord, string etc
 - Sponge or some soft foam
 
 **Printed parts**

- 2x	Sunshade(mirror the second one) - `sunshade.step`
- 2x Sunshade small (optional) - `sunshade_small.step`
- 1x	Flap - `flap.step` 
- 1x Bearing holder - `bearing_holder.step`
- 1x Bearing collar - `bearing_collar.step`
- 1x Sensor holder - `sensor_holder.step`

You need 4x of M3 washers, bolts(10mm) and nuts for connecting one sensor to the accessory holder.

## Stirrup Sensor
You need to make two of these, the left and right parts are identical.

**BOM**
 - 1x M3 Bolt 10mm
 - 25mm strap
 - 25mm strap adjuster
 
 
 **Printed parts**

- 1x Stirrup - `stirrup.step`
- 1x Stirrup plate - `stirrup_antislip_holder.step`
- 1x Stirrup Reflector - `stirrup_reflector_plate.step`
- 1x Sunshade  - `sunshade.step`
- 1x Sensor holder - `sensor_holder.step`

You need 4x of M3 washers, bolts(10mm) and nuts for connecting one sensor to the accessory holder.


## Nunchuck Connector

**BOM**
 - 2x M3 Bolt 16mm
 - 2x M3 Heatset insert OD 5mm
 - 3mm zip tie
 - 1x "I2C for Wii, WiiChuck Nunchuck Board"
 
 **Printed parts**

- 1x Lid - `nunchuck_connector_lid.step`
- 1x Case - `nunchuck_connector_body.step`
- 1x Holder - `nunchuck_connector_holder.step`
- 1x Controller holder - `nunchuck_controller_holder.step`
- 
You need 4x of M3 washers, bolts(10mm) and nuts for connecting the controller holder to the accessory holder.

## Electronic Box

Currently there is no PCB design so electronics need to be handwired. 

**BOM**
 - 4x M3 Bolt 10mm
 - 6x M3 Heatset insert OD 5mm
 - 70x50mm Perfboard
 - 2x short M3 bolt+washers
 - 6x MX compatible keyswitches
 - Solder, wire etc
 
 **Printed parts**

- 1x Lid - `electronics_box_lid.step`
- 1x Case - `electronics_box_main_body.step`

You need 4x of M3 washers, bolts(10mm) and nuts for connecting the controller holder to the accessory holder.
